Kebijakan Privasi / Privacy Policy

Panen SiRUP · Berlaku sejak / Effective: 5 Oktober 2026 (October 5, 2026)

Bahasa Indonesia

Data Google yang diakses. Saat pengguna memilih "Hubungkan Google", aplikasi meminta:

  • alamat email akun Google, hanya untuk menampilkan akun mana yang sedang terhubung;
  • izin drive.file, untuk membuat dan memperbarui satu Google Sheet ("Data Pengadaan SiRUP") milik pengguna. Aplikasi tidak bisa melihat, membaca, atau mengubah file lain di Google Drive pengguna.

Cara data digunakan dan disimpan. Aplikasi berjalan sepenuhnya di komputer pengguna. Izin login (token) dan email disimpan di file lokal token_google.json di komputer pengguna. Tidak ada server milik pengembang. Data tidak dikirim, dijual, atau dibagikan ke pihak mana pun selain Google (untuk menulis ke Google Sheet pengguna) dan situs SiRUP (untuk mengambil data publik).

Menghapus data dan mencabut izin. Klik "Putuskan akun Google" di aplikasi untuk menghapus token lokal, atau cabut akses kapan saja di myaccount.google.com/permissions. Google Sheet yang sudah dibuat tetap milik pengguna dan bisa dihapus dari Google Drive.

Penggunaan informasi dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

English

Google data accessed. When the user chooses "Connect Google", the app requests:

  • the Google account email address, only to show which account is connected;
  • the drive.file scope, to create and update one Google Sheet ("Data Pengadaan SiRUP") owned by the user. The app cannot see, read, or modify any other file in the user's Google Drive.

How data is used and stored. The app runs entirely on the user's computer. The login token and email are stored in a local file (token_google.json) on the user's computer. There is no developer server. Data is not sent, sold, or shared with anyone other than Google (to write to the user's own Google Sheet) and the SiRUP website (to fetch public data).

Deleting data and revoking access. Click "Putuskan akun Google" (Disconnect) in the app to delete the local token, or revoke access at any time at myaccount.google.com/permissions. Sheets already created remain the user's property and can be deleted from Google Drive.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
